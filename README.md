# 🍲 API de Recetas de Comida con Gestión de Usuarios

Esta API desarrollada en **Spring Boot** permite acceder a un repositorio de recetas de comida y gestionar usuarios. Además, incluye un **frontend** que facilita la consulta de datos directamente desde la interfaz gráfica conectándose a la API.

## 🚀 Características

- **Gestión de Usuarios**:
  - Registro, autenticación y actualización de perfiles.
  - Roles y permisos para acceso a funcionalidades específicas.

- **Recetas de Comida**:
  - Consultar recetas disponibles.
  - Agregar, editar y eliminar recetas (según permisos de usuario).
  - Búsqueda y filtrado por categorías, ingredientes, etc.

- **Frontend Integrado**:
  - Permite interactuar con la API de manera intuitiva.
  - Muestra las recetas y permite gestionar la cuenta de usuario.
